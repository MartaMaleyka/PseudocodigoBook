## 📚 Acceso

El ebook está disponible en GitHub Pages:

👉 **[Leer el ebook](https://martamaleyka.github.io/pseudocodigobook/)**

## 📝 Contenido

- **11 Capítulos** progresivos sobre pseudocódigo y algoritmos
- **Ejemplos prácticos** con código en múltiples lenguajes
- **Casos de uso** del mundo real
- **Diseño responsivo** con soporte light/dark mode

## 🚀 Desarrollo local

Para visualizar el ebook localmente:

```bash
# Abrir directamente en el navegador
open docs/index.html

# O usar un servidor local
python -m http.server 8000
# Luego acceder a http://localhost:8000/docs/
```

## ⚙️ GitHub Pages

Este repositorio usa GitHub Pages con la rama `master` y la carpeta `docs/`. Los cambios se publican automáticamente.
